What UAM is

UAM is a planned replacement for an old Windows activity-monitoring system. The future Windows client would collect only approved application and browser activity, remove or transform information according to approved privacy rules, keep allowed events safely while offline, and send them to a server that accepts each event once.

Where we are: Preparation before G0 implementation. This is a planning and evidence repository. Production code and production approval do not exist.

What would stop or invalidate this plan?

  • An unresolved human decision is turned into a production default.
  • Real, personal, internal, credential, or unclassified data enters G0.
  • The generator or oracle is nondeterministic or shares the implementation logic it is meant to check.
  • A required canary, mutation, cleanup check, owner, or evidence binding is missing at gate closure.
