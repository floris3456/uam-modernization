# Small glossary

**ADR** — A short record of an important architecture decision, its reason, alternatives, and consequences.

**Contract** — The exact shape and meaning of information exchanged between parts of the system.

**Cursor** — A saved position showing which source records were safely processed. A bad cursor can skip or duplicate activity.

**Evidence** — A stored result from a reproducible test, measurement, inspection, or approved source.

**Gate** — A stop point. Work beyond it waits until required evidence exists and a human accepts the remaining risk.

**Oracle** — An independent way to calculate the answer a test should produce.

**Outbox** — A local durable queue holding items until the server confirms receipt.

**Realm** — A security boundary whose information must remain separate from other realms.

**Sanitized profile** — Counts and quality facts derived from a source without copying sensitive row values.

**Test fixture** — Fixed fictional input used to reproduce a test.
