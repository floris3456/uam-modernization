# DEV screenshot evidence

This directory contains 20 privacy-masked PNG captures from the UAM Activity Monitor DEV app. The documented interaction boundary was:

- tab navigation;
- temporary search/filter input;
- sortable column headers;
- previous/next pagination.

Add, edit, delete, save, export, row actions and task/script execution were excluded. Before capture, table/grid rows, input values, canvas labels and account labels were visually masked.

The current `walkthrough.json` records the latest recapture attempt, which stopped on the PSU login page and did not replace the existing PNG evidence. It is not a successful-screen manifest. A fresh DEV or PROD capture requires a valid interactive PSU login; credentials, cookies and browser profiles are deliberately not stored.

The existing PNG set is the source for the walkthrough PDF and video. Its filenames distinguish normal views from the safe read-interaction evidence.
