# PDF-einddocumenten

De PDF-set bevat:

- `UAM-IST-samenvatting-A4.pdf`: huidige situatie op één A4;
- `UAM-doelbeeld-samenvatting-A4.pdf`: gewenste situatie op één A4;
- `UAM-legacy-overdrachtsdossier.pdf`: agentanalyse, samenvattingen,
  C#-architectuur en migratieroadmap;
- `UAM-databasemodel-en-data-dictionary.pdf`: diagrammen en alle 569
  veldrecords;
- `UAM-PSU-app-IST.pdf`: portaalanalyse met privacygemaskeerde
  DEV-schermafdrukken.

De PDF's worden uit de Markdown-bronnen gegenereerd met
`scripts/New-UamDocumentationPdfs.ps1`. De bijbehorende HTML-bestanden blijven
onder `deliverables/html` beschikbaar voor toegankelijkheid en regeneratie.
