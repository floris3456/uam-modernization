# Repeatable research workflow

1. **Start** — create one package card for one decision area; state scope, decision informed, status, and output mode.
2. **Scaffold** — keep each bounded study's prompt, public-safe attachments, result target, and review together.
3. **Run** — use an exact repository ref and the smallest useful reading list. For dataset-dependent work, bind the current randomized dataset identity and use only covered property/value claims; preserve returned evidence at its declared target.
4. **Validate** — run repository research validation and reconcile contradictions explicitly.
5. **Dispose** — a human decides whether conclusions become a design proposal, gate input, AS-BUILT fact, deviation, or other record.
6. **Preserve** — results and raw external evidence remain immutable; refresh provenance/hash records through the established generator when intentional package metadata changes.

Do not ingest production data, private chat, secrets, or unnecessary sensitive values. Do not treat theoretical commands as executed evidence.

Every new research prompt declares `Dataset use: NONE` with a reason or `Dataset use: RANDOMIZED_VALUES` with the exact contract identity. Randomized values and declared properties may support positive examples; all constructed structure, identities, clocks, boundaries, canaries, and negative mutations are `TEST_AUTHORED`. Dataset absence or mismatch puts only dependent claims in `HOLD`.
