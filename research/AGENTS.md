# Research evidence rules

Follow the root `AGENTS.md`. Within `research/`:

- Treat populated result files as preserved evidence. Do not summarize, reformat, or rewrite them casually.
- Implementation prompt files, indexes, context, attachments, and manifests are generator-owned. Change `scripts/generate-implementation-research.mjs` first.
- Root and baseline indexes are generated by `scripts/generate-research-index.mjs`.
- The canonical Batch 4 review is `implementation/batches/04-server-platform/review/result-review-04-server-platform.md`.
- Keep every study prompt and uniquely named result in the same study directory.
- Declare every prompt, result, attachment, and predecessor dependency in the relevant manifest.
- Never add raw catalogues, SSH material, private/internal addresses, credentials, confidential SQL, personal information, or production data.
- Research statements are recommendations or source evidence, not accepted ADRs, measurements, or production approval.
- When a research result changes intentionally, regenerate `evidence/manifests/research-evidence.json` and record why in the task handoff.

Run `./scripts/validate-repository.sh` from the repository root before handoff.
